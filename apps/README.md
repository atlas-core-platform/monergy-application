# Applications

This responsibility contains the two D05 application boundaries.

`customer-web` retains the D02 toolchain-verification shell using the approved
React, Vite, Ant Design and Tailwind foundation. It demonstrates startup/build
metadata, a keyboard-accessible Ant Design interaction, semantic tokens,
responsive layout, an error boundary, component/accessibility tests and a
Playwright smoke test. D03 adds the separately loaded `/vs02` implementation-
candidate route for the eight canonical Evidence-to-Financial-Truth Features.
It exposes loading, empty, validation, success and classified failure states,
and labels all results as LOCAL/CI reference evidence.

`administration-web` remains reserved. No administration behavior is
implemented.
