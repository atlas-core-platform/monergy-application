# Applications

This responsibility contains the two D05 application boundaries.

`customer-web` is a minimal D02 toolchain-verification shell using the approved
React, Vite, Ant Design and Tailwind foundation. It demonstrates startup/build
metadata, a keyboard-accessible Ant Design interaction, semantic tokens,
responsive layout, an error boundary, component/accessibility tests and a
Playwright smoke test. It is technology evidence, not a Monergy Feature.

`administration-web` remains reserved. No business presentation behavior is
implemented in either application.
